# Security Policy

## Reporting a Vulnerability

Do **not** open a public GitHub issue for security vulnerabilities.

Email: `founder@manar.pk`  
Subject: `[SECURITY] manar-qc — <brief description>`

We will respond within 48 hours. See `docs/SECURITY.md` for the full policy.

## Supported Versions

| Version | Supported |
|---------|-----------|
| main    | ✅ Yes     |
| older   | ❌ No      |
